# Laboratorio SAMBA
1 - Instalamos y creamos nuestra máquina Ubuntu Server
 1.1 Hacemos clic en Nueva en VirtualBox. Nombre: "Ubuntu-Server-Lab". Tipo: Linux, Versión: Ubuntu (64-bit).
 1.2 Asignamos 2048 MB de RAM (2 GB) y 1 CPU como mínimo.
 1.3 Crea un disco duro virtual de 15 GB (VDI, reservado dinámicamente).
 1.4 En la configuración de la máquina virtual, en la pestaña Red, habilita el Adaptador 1 y conéctalo a la red Host-Only que creaste en el paso anterior.
 1.5 Inicia la máquina, selecciona la ISO de Ubuntu Server que descargaste y sigue el instalador. Durante el proceso, define tu usuario administrador (por ejemplo, "administrador").
